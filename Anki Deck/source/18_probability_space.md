=== 18 | Probability Space & Random Variables ===

[QA]
Q:
Define a <b>probability space</b> \((\Omega,\mathcal{F},P)\).
A:
<ul>
<li>\(\Omega\) — <b>sample space</b>, the set of all outcomes.</li>
<li>\(\mathcal{F}\) — the <b>events</b>, a \(\sigma\)-algebra (contains \(\emptyset,\Omega\); closed under complement and countable unions/intersections).</li>
<li>\(P:\mathcal{F}\to[0,1]\) — a <b>probability measure</b>.</li>
</ul>

[QA]
Q:
State the <b>axioms of probability</b>.
A:
<ol>
<li>\(P(\emptyset)=0,\ P(\Omega)=1\);</li>
<li>\(0\le P(E)\le1\) for all \(E\in\mathcal{F}\);</li>
<li><b>Countable additivity:</b> for disjoint \(E_1,E_2,\dots\), \(P\big(\bigcup_i E_i\big)=\sum_i P(E_i)\).</li>
</ol>

[QA]
Q:
Why do we need a \(\sigma\)-algebra \(\mathcal{F}\) instead of "all subsets" of \(\Omega\)?
A:
For continuous \(\Omega\) (e.g. \([0,2\pi)\)) it is <b>impossible</b> to assign a consistent probability to <i>every</i> subset. The events must be restricted to a \(\sigma\)-algebra (e.g. the Borel sets generated by half-open intervals).
E:
The Cantor set illustrates pathological sets; full rigor needs Lebesgue measure. In robotics we stay with sets we can integrate over (Riemann/Riemann–Stieltjes).

[QA]
Q:
Define a (real) <b>random variable</b> \(X:\Omega\to\mathbb{R}\).
A:
A function such that for every \(x\in\mathbb{R}\), the preimage \(\{\omega\in\Omega:X(\omega)\le x\}\in\mathcal{F}\) — i.e. \(P(X\le x)\) is well defined.
E:
"Measurable": every threshold event has an assignable probability. A <b>random vector</b> is a vector whose every component is a random variable.

[QA]
Q:
Define a <b>probability density</b> and a <b>continuous random variable</b>.
A:
\(f:\mathbb{R}\to[0,\infty)\) (piecewise continuous) is a density if \(\int_{-\infty}^\infty f(x)\,dx=1\). \(X\) is a continuous random variable with density \(f\) (\(X\sim f\)) if
\[ P(X\le x)=\int_{-\infty}^x f(\bar x)\,d\bar x. \]
E:
The density lets you compute \(P(X\in A)=\int_A f\,dx\) directly on the range, bypassing the abstract space \((\Omega,\mathcal{F},P)\).

[QA]
Q:
Define the <b>mean</b>, <b>variance</b>, and <b>standard deviation</b> via a density.
A:
\[ \mu=E\{X\}=\int_{-\infty}^\infty x f(x)\,dx,\quad \sigma^2=E\{(X-\mu)^2\}=\int_{-\infty}^\infty (x-\mu)^2 f(x)\,dx,\quad \sigma=\sqrt{\sigma^2}. \]

[QA]
Q:
Give the <b>uniform</b> and <b>Gaussian</b> densities.
A:
Uniform on \([a,b]\): \(f(x)=\tfrac{1}{b-a}\) for \(x\in[a,b]\), else \(0\).
<br>Gaussian \(N(\mu,\sigma)\): \(\displaystyle f(x)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}\).

[CLOZE]
C:
A probability space is \((\Omega,\mathcal{F},P)\) where \(\mathcal{F}\) is a {{c1::\(\sigma\)-algebra}} of events and \(P\) satisfies {{c2::countable additivity}}. A function \(X:\Omega\to\mathbb{R}\) is a random variable iff \(\{X\le x\}\in\mathcal{F}\) for all \(x\), i.e. it is {{c3::measurable}}.
